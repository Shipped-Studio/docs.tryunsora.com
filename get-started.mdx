Unsora is a social media scheduler for AI agents. Connect your social accounts once, then post and schedule to TikTok, Instagram, YouTube, Facebook, LinkedIn, X, Threads, Bluesky, Pinterest and Google Business Profile from ChatGPT, Claude, Cursor, the CLI or the REST API. **Content Studio**, in the same account, generates the video, images, music and voice for those posts.

Use this page to create an API key and make your first request.

<Tip>
  Working from an AI assistant instead of code? Add the MCP server at `https://mcp.tryunsora.com/mcp` — see [MCP server](/integrations/mcp).
</Tip>

## 1) Create an API key

1. Sign in to the [Unsora dashboard](https://app.tryunsora.com).
2. In the sidebar, under **Developers**, open **API keys** (`/api-keys`).
3. Click **Create API key**.
4. Copy the key immediately and store it in a password manager.

Keys look like `uns_...`.

## 2) Add the key to requests

Send the key as a Bearer token on every request:

```bash
curl https://mvp.tryunsora.com/api/v1/user/credits \
  -H "Authorization: Bearer uns_..."
```

The base URL is `https://mvp.tryunsora.com/api/v1`.

## 3) Verify auth

If the request returns `200`, your key works. The response is your credit balance — see [Credits](/api-reference/user/credits).

## 4) Schedule a post

Connect your social accounts in the dashboard first ([Connect accounts](/guides/connect-accounts)). Then:

1. Find the account ids with [List accounts](/api-reference/accounts/get_accounts) (`GET /accounts`).
2. Create the post with [Create post](/api-reference/posts/create_post) (`POST /posts`) — pass a caption, media URLs and a `scheduled_at` time, or publish straight away.

Posting needs a paid plan (every plan starts with a 7-day free trial). Without one, post requests return `403` with code `PLAN_REQUIRED`. See [Plans and credits](/guides/plans-and-credits).

## 5) Generate content

Generation jobs are async: create the job, then poll its status until it is `COMPLETED` or `FAILED`.

- [Create image](/api-reference/image-generations/create) (`POST /image-generations/create`), then poll `GET /image/status/:id`
- [Create video](/api-reference/video/create) (`POST /videos/create`), then poll `GET /video/status/:id`
- [Create song](/api-reference/music-generations/create) (`POST /music-generations/create`), then poll `GET /music/status/:id`
- [Create voiceover](/api-reference/voiceovers/create) (`POST /voiceovers/create`), then poll `GET /voiceovers/status/:id`

Generation spends credits, which come from one-time credit packs. Check live models and prices with `GET /catalog` and `POST /catalog/quote` before you run a job.
