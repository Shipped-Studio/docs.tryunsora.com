---
title: "List uploads"
description: "Paginated list of your uploaded media assets, including file type, size, and URLs, ready to attach to posts and generation jobs."
openapi: "GET /uploads"
---

Returns your uploaded assets (newest first), paginated with `page` and `limit`
(max 100). This includes files you uploaded or imported and the media URLs you
passed to [Create post](/api-reference/posts/create_post), which are stored as
uploads too. Generated media lives on its own generation endpoints.
