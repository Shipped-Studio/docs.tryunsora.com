---
title: "Poll generation status"
description: "Check the status of image, AI influencer, thumbnail, image upscale and movie-material jobs. Returns the latest state and the output URL when complete."
openapi: "GET /image/status/{id}"
---

One polling endpoint for every job that produces an image: **image generator**, **AI influencer**, **thumbnail**, **image upscaler** and **movie materials** jobs.

Use the `id` returned from any create response. Poll every few seconds until `status` is `COMPLETED` or `FAILED`.

```bash
curl "https://mvp.tryunsora.com/api/v1/image/status/GENERATION_ID" \
  -H "Authorization: Bearer uns_YOUR_API_KEY"
```

Example response:

```json
{
  "success": true,
  "data": {
    "id": "cm123...",
    "status": "COMPLETED",
    "outputUrl": "https://...",
    "error": null,
    "createdAt": "2026-06-02T12:00:00.000Z",
    "updatedAt": "2026-06-02T12:01:30.000Z",
    "completedAt": "2026-06-02T12:01:30.000Z"
  }
}
```

The response has no job-type field; you know the type from the endpoint that created the job. `status` is one of `QUEUED`, `PROCESSING`, `COMPLETED` or `FAILED`.
