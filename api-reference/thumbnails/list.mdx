---
title: "List thumbnails"
description: "All thumbnail generations for the authenticated user."
openapi: "GET /public/thumbnails"
---

Returns thumbnail jobs for the authenticated user, newest first.

**`GET /public/thumbnails`**

## Response

```json
{
  "success": true,
  "data": [
    {
      "id": "cm123abc",
      "userId": "user_...",
      "title": "How to grow on YouTube in 2026",
      "description": null,
      "image": "https://files.tryunsora.com/....jpg",
      "link": null,
      "jobId": "task_...",
      "status": "COMPLETED",
      "error": null,
      "completedAt": "2026-06-02T12:01:00.000Z",
      "createdAt": "2026-06-02T12:00:00.000Z",
      "updatedAt": "2026-06-02T12:01:00.000Z"
    }
  ]
}
```

## Example

```bash
curl "https://sadek.tryunsora.com/api/v1/public/thumbnails" \
  -H "Authorization: Bearer uns_live_YOUR_API_KEY"
```
