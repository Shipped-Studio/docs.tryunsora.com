---
title: "Create thumbnail"
description: "Generate click-worthy YouTube thumbnails from a title, script, or reference image — returns a job you can poll until the images are ready."
openapi: "POST /thumbnails/create"
---

Pass YouTube URL in `context` for YouTube thumbnail mode:

```json
{
  "prompt": "Bold title, shocked face",
  "context": [{ "type": "youtube", "content": "https://youtube.com/watch?v=..." }],
  "variations": 3
}
```

`context` takes exactly one item: a YouTube link (`youtube`) or a public PDF (`document`). With more than one item, or a link that doesn't match its type, the context is ignored without an error, so check the item before you send it. `label` works in place of `content`.

Each variation is a separate job and costs 12 credits. `variations` outside 1–20 is clamped, and an unknown `expression` falls back to `auto`. Poll each id with [Poll image status](/api-reference/image/poll-status).
