---
title: "Get generation"
description: "Fetch a single music generation by ID."
openapi: "GET /public/music-generations/{generationId}"
---

Returns one music generation record including `outputAsset` when complete.

**`GET /public/music-generations/{generationId}`**

## Path parameters

<ParamField path="generationId" type="string" required>
  Generation ID from the create response.
</ParamField>

## Example

```bash
curl "https://sadek.tryunsora.com/api/v1/public/music-generations/cm123abc" \
  -H "Authorization: Bearer uns_live_YOUR_API_KEY"
```
