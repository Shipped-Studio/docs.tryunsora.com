---
title: "Delete talking avatar"
description: "Delete a talking-avatar generation record from your Unsora account."
openapi: "DELETE /avatar-generations/{generationId}"
---

```bash
curl -X DELETE "https://mvp.tryunsora.com/api/v1/avatar-generations/GENERATION_ID" \
  -H "Authorization: Bearer uns_YOUR_API_KEY"
```
