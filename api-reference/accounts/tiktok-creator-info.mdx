---
title: "TikTok creator info"
description: "Get a connected TikTok account's posting options, such as the privacy levels it allows and whether comments, duets and stitches can be turned on."
openapi: "GET /accounts/{accountId}/tiktok/creator-info"
---

Returns what TikTok allows for one connected account: the privacy levels you can use, whether comments, duets and stitches are available, and the maximum video length. Check it before setting `settings.tiktok` in [Create Post](/api-reference/posts/create_post).

```bash
curl "https://mvp.tryunsora.com/api/v1/accounts/ACCOUNT_ID/tiktok/creator-info" \
  -H "Authorization: Bearer uns_YOUR_API_KEY"
```
