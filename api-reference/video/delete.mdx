---
title: "Delete video generation"
description: "Permanently delete a video generation record from your Unsora account. The video file stays in your library. This action cannot be undone."
openapi: "DELETE /videos/{generationId}"
---

Deletes one video generation record owned by the authenticated user. The output video file isn't deleted; it stays in your library.

**`DELETE /videos/{generationId}`**

## Path parameter

<ParamField path="generationId" type="string" required>
  Generation id from [Create video](/api-reference/video/create) or [List video generations](/api-reference/video/list).
</ParamField>

## Response

```json
{
  "success": true,
  "message": "Generation deleted successfully"
}
```

## Example

```bash
curl -X DELETE "https://mvp.tryunsora.com/api/v1/videos/GENERATION_ID" \
  -H "Authorization: Bearer uns_YOUR_API_KEY"
```

## Errors

| HTTP | When |
| --- | --- |
| `400` | Missing generation id |
| `401` | Invalid auth |
| `404` | User or generation not found |
| `500` | Server error |
