Creates a video generation with any supported video model. Credits are charged when the job is queued. Poll [Poll video status](/api-reference/video/poll-status) with `generation.id` until `status` is `COMPLETED` or `FAILED`.

This endpoint takes a simple, fixed set of fields and translates them onto the chosen model. It runs through the same live pricing as [Generate](/api-reference/catalog/generate), which exposes every input a model has. New integrations should use the catalog endpoints.

Not sure [which video model to use](https://tryunsora.com/ai-video-generator)? Start with the comparison, then pick a key below.

## Supported models

Pass the model key in the `model` body field. Default: `seedance-2.0`.

| Model key | Name |
| --- | --- |
| `seedance-2.5` | Seedance 2.5 |
| `seedance-2.5-turbo` | Seedance 2.5 Turbo |
| `seedance-2.0` | Seedance 2.0 |
| `seedance-2.0-fast` | Seedance 2.0 Fast |
| `seedance-2.0-mini` | Seedance 2.0 Mini |
| `veo-3.1` | Veo 3.1 |
| `veo-3.1-fast` | Veo 3.1 Fast |
| `veo-3.1-lite` | Veo 3.1 Lite |
| `gemini-omni-1.1-flash` | Gemini Omni 1.1 Flash |
| `kling-o3-pro` | Kling O3 Pro |
| `kling-3.0-pro` | Kling 3.0 Pro |
| `kling-3.0-std` | Kling 3.0 Standard |
| `wan-3.0` | Wan 3.0 |
| `grok-imagine-video-1.5` | Grok Imagine Video 1.5 |
| `sora-2` | Sora 2 |
| `sora-2-pro` | Sora 2 Pro |

Older names still work: `veo`, `veo-fast`, `veo-lite`, `kling-pro`, `kling-standard`, `gemini-omni-flash`, `seedance_2.0`, `sora_2` and `sora_2_pro`. `wan` and `wan_2.6` now run as `wan-3.0`.

Durations, aspect ratios, resolutions, audio and how many reference files each model takes differ by model. [List models](/api-reference/catalog/list) returns every model's inputs with their allowed values.

## Headers

| Header | Required | Description |
| --- | --- | --- |
| `Authorization` | Yes | `Bearer uns_*` API key or Clerk JWT |
| `Idempotency-Key` | No | Max 128 chars. Replays the same response for 24h on API key requests |
| `Content-Type` | Yes | `application/json` |

## Request body

Fields a model doesn't take are ignored, and anything you leave out uses the model's own default. snake_case spellings work too (`aspect_ratio`, `negative_prompt`, `generate_audio`, `start_frame`, `last_image`, `reference_images`, …).

<ParamField body="prompt" type="string">
  What the video shows. Required for text-to-video. Image-to-video and reference modes that run from attached media can go without it.
</ParamField>

<ParamField body="model" type="string">
  Video model key from the table above. Default: `seedance-2.0`.
</ParamField>

<ParamField body="mode" type="string">
  Generation mode, for models that have more than one: `omni_reference`, `first_last_frames` or `REFERENCE_2_VIDEO` (also `omni`, `FIRST_AND_LAST_FRAMES_2_VIDEO`, `reference`). Left out, the mode is picked from the media you attach. `functionMode` is an alias.
</ParamField>

<ParamField body="duration" type="integer">
  Length in seconds. Valid values depend on the model.
</ParamField>

<ParamField body="aspectRatio" type="string">
  Aspect ratio, such as `16:9` or `9:16`. Valid values depend on the model; `auto` uses the model's default.
</ParamField>

<ParamField body="resolution" type="string">
  Output resolution, such as `720p` or `1080p`, for models that offer it.
</ParamField>

<ParamField body="negativePrompt" type="string">
  What to avoid, for models that take one.
</ParamField>

<ParamField body="sound" type="boolean">
  Generate audio with the video, for models that offer it. Usually costs more. `generateAudio` is an alias on every model.
</ParamField>

<ParamField body="image" type="string">
  Start frame for image-to-video. Alias: `startFrame`.
</ParamField>

<ParamField body="lastImage" type="string">
  End frame, for models that support start and end frames. Aliases: `endImage`, `endFrame`.
</ParamField>

<ParamField body="filePaths" type="string[]">
  Start and end frame as a list: the first item is the start frame, the second the end frame.
</ParamField>

<ParamField body="imageUrls" type="string[]">
  An image list. In reference mode these are the reference images; otherwise the first two are the start and end frames.
</ParamField>

<ParamField body="referenceImages" type="string[]">
  Reference image URLs. The maximum count depends on the model.
</ParamField>

<ParamField body="referenceVideos" type="string[]">
  Reference video URLs, for models that take them.
</ParamField>

<ParamField body="referenceAudios" type="string[]">
  Reference audio URLs, for models that take them.
</ParamField>

Media URLs hosted outside Unsora are copied into your library before the job starts, up to 12 per request. Upload more with [Upload media](/api-reference/uploads/create) first.

## Credits

Each run is priced live from the provider's cost for those exact inputs (model, duration, resolution, audio). Get the price before you generate with [Quote a generation](/api-reference/catalog/quote); `creditsDeducted` in the response is what was charged.

## Async completion

Poll `GET /video/status/{id}`. See [Poll video status](/api-reference/video/poll-status). No webhooks.

## Response

```json
{
  "success": true,
  "model": "seedance-2.0",
  "generation": {
    "id": "cm123abc",
    "status": "QUEUED",
    "model": "seedance-2.0",
    "mode": "omni",
    "modelId": "bytedance/seedance-2.0/text-to-video"
  },
  "creditsDeducted": 40,
  "creditsRemaining": 60
}
```

`generation.modelId` is the provider endpoint the request routed to.

## Errors

| HTTP | When |
| --- | --- |
| `400` | Invalid model, mode or inputs; a media file couldn't be read or imported; or more than 12 outside media URLs |
| `401` | Invalid auth |
| `402` | Insufficient credits |
| `404` | User not found |
| `409` | `IDEMPOTENCY_CONFLICT`: the Idempotency-Key was already used on a different endpoint |
| `429` | Rate limit exceeded |
| `502` | The pricing service couldn't be reached. Try again |
| `503` | `PROVIDER_UNAVAILABLE`: generation is temporarily unavailable. Nothing was charged |
