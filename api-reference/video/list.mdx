---
title: "List video generations"
description: "Paginated list of Seedance 2.0 video jobs for the authenticated user."
openapi: "GET /public/videos/all"
---

Returns **Seedance 2.0** (`seedance_2.0`) video generations for the authenticated user, newest first.

**`GET /public/videos/all`**

## Query parameters

<ParamField query="page" type="integer" default="1">
  Page number (1-based).
</ParamField>

<ParamField query="limit" type="integer" default="12">
  Items per page. Min `1`, max `100`.
</ParamField>

## Example

```bash
curl "https://sadek.tryunsora.com/api/v1/public/videos/all?page=1&limit=12" \
  -H "Authorization: Bearer uns_live_YOUR_API_KEY"
```

## Errors

| HTTP | When |
| --- | --- |
| `401` | Invalid auth |
| `404` | User not found |
| `500` | Server error |
