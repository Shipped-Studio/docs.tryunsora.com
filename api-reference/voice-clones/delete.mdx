---
title: "Delete cloned voice"
description: "Delete one of your cloned voices. It can no longer be used as a voice_id."
openapi: "DELETE /voice-clones/{cloneId}"
---

```bash
curl -X DELETE "https://mvp.tryunsora.com/api/v1/voice-clones/CLONE_ID" \
  -H "Authorization: Bearer uns_YOUR_API_KEY"
```
