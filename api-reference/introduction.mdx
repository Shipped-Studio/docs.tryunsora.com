Unsora's public API covers the social media scheduler (connected accounts, posts, analytics) and Content Studio (AI generation and clipping). Everything you can do from an AI agent over MCP, you can do here.

## Base URL

```
https://mvp.tryunsora.com/api/v1
```

## Authentication

Send an Unsora API key (or a Clerk session token) as a Bearer token:

```bash
Authorization: Bearer uns_...
```

Create keys in the dashboard under **Developers → API keys**. See [Get started](/get-started) and [API guide](/api-guide).

## OpenAPI

The reference pages are generated from `openapi.json` at the root of the docs repo.

External tools can import the live spec:

- `GET https://mvp.tryunsora.com/api/v1/openapi.json`
- `GET https://mvp.tryunsora.com/api-docs/openapi.json`

## Security scheme

Protected endpoints declare:

```json
"security": [{ "bearerAuth": [] }]
```

`bearerAuth` accepts `uns_*` API keys or Clerk session tokens.

## MCP

Prefer an AI assistant? The same features are available as tools on the MCP server at `https://mcp.tryunsora.com/mcp`. See [MCP server](/integrations/mcp).
