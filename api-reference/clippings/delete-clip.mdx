---
title: "Delete clip"
description: "Delete one clip from a finished AI clipping job, keeping the job and its other clips."
openapi: "DELETE /clippings/{clippingId}/clips/{clipId}"
---

Removes one clip from a clipping job. The job and its other clips stay.

```bash
curl -X DELETE "https://mvp.tryunsora.com/api/v1/clippings/CLIPPING_ID/clips/CLIP_ID" \
  -H "Authorization: Bearer uns_YOUR_API_KEY"
```
