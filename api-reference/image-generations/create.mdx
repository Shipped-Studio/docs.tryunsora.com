---
title: "Create image"
description: "Queue an AI image generation job and poll until complete."
openapi: "POST /public/image-generations/create"
---

Creates an image generation job. Credits are deducted when the job is queued. Poll [Poll generation status](/api-reference/image/poll-status) with the returned `generation.id` until `status` is `COMPLETED` or `FAILED`.

## Headers

| Header | Required | Description |
| --- | --- | --- |
| `Authorization` | Yes | `Bearer uns_live_*` API key or Clerk JWT |
| `Idempotency-Key` | No | Max 128 chars. Replays the same response for 24h on API key requests |
| `Content-Type` | Yes | `application/json` |

## Request body

<ParamField body="prompt" type="string" required>
  Text prompt for the image.
</ParamField>

<ParamField body="model" type="string">
  Model key. Default: `nano-banana-2`.

  Supported values: `nano-banana-2`, `nano-banana-pro`, `seedream-v5-lite`, `gpt-image-1.5`, `gpt-image-2`.

  Each model accepts different `ratio` and `resolution` values, credit costs, and reference-image limits. See [Image models](/guides/image-generator/models) for the full aspect ratio and resolution reference.
</ParamField>

<ParamField body="ratio" type="string">
  Aspect ratio. Must be allowed for the chosen `model`. Default: `auto` (where supported). Not used for `gpt-image-1.5` — use `resolution` pixel dimensions instead.
</ParamField>

<ParamField body="resolution" type="string">
  Output size or quality tier. Must match the chosen `model`. Default: `2k` for most models. For `gpt-image-1.5`, use `1024x1024`, `1024x1536`, or `1536x1024`. For `seedream-v5-lite`, use `basic` or `high`.
</ParamField>

<ParamField body="referenceImageUrl" type="string">
  Single reference image URL (public HTTPS). Use for style or subject guidance.
</ParamField>

<ParamField body="referenceImageUrls" type="string[]">
  Multiple reference image URLs. Max count depends on model (up to 14–16). If both `referenceImageUrl` and `referenceImageUrls` are sent, the array wins.
</ParamField>

<ParamField body="nsfwChecker" type="boolean">
  Enable NSFW filtering when supported by the provider pipeline.
</ParamField>

## Async completion

Poll [Poll generation status](/api-reference/image/poll-status) with `generation.id` until `status` is `COMPLETED` or `FAILED`. Webhooks are not supported on the public API.

## Response

```json
{
  "success": true,
  "generation": {
    "id": "cm123abc",
    "status": "QUEUED"
  },
  "creditsDeducted": 5,
  "creditsRemaining": 95
}
```

## Example

<RequestExample>
```bash Basic theme={null}
curl -X POST "https://sadek.tryunsora.com/api/v1/public/image-generations/create" \
  -H "Authorization: Bearer uns_live_YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "Product photo on marble, soft studio light",
    "model": "nano-banana-2",
    "ratio": "1:1",
    "resolution": "2k"
  }'
```

```bash With references theme={null}
curl -X POST "https://sadek.tryunsora.com/api/v1/public/image-generations/create" \
  -H "Authorization: Bearer uns_live_YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "Same character, new outfit, editorial look",
    "model": "gpt-image-2",
    "ratio": "9:16",
    "resolution": "2k",
    "referenceImageUrls": [
      "https://cdn.example.com/ref-1.jpg"
    ]
  }'
```
</RequestExample>

## Errors

| HTTP | When |
| --- | --- |
| `400` | Missing/invalid prompt, model, ratio, resolution, or too many reference images |
| `401` | Invalid auth |
| `402` | Insufficient credits |
| `404` | User not found |
| `429` | Rate limit exceeded |
| `500` | Server error |
